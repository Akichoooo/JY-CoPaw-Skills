# alarm-accuracy-report — 预警准确率日报 / 月报

## 用途

把预警平台导出的“预警详情”Excel 变成：

1. 当天各技能的预警准确率日报；
2. 写入 `准确率台账.csv`，按月汇总成月报。

## 输入

- 预警平台导出的 `.xlsx`，工作表含表头：`预警名称`、`预警ID`、`预警点位`、`预警技能`、`所属组织`、`处理状态`、`预警时间` 等。
- 用户口述的误报条数，按 `预警技能` 给。
- 脚本按 `预警技能` 列分组计数；`预警名称` 不参与统计。

## 口径（必须遵守）

- 准确率 =（预警总数 − 误报数）÷ 预警总数；月准确率按条数加权，不是日准确率的简单平均。
- 误报数必须由用户提供。**不要自行猜测，不要从图片或描述推断。**
- 只有用户明确说“其他都准确”时，未提到的技能才按 0 误报；否则先追问。
- 用户说“XX 都是误报” → `--false "XX=all"`。
- 技能名用导出表里的精确名称。用户用简称时，先跑 `--list-skills`，把简称映射到唯一技能；有歧义就问。
  - 本项目默认：“夜间入侵” = 「夜间区域入侵」；「夜间人员停留」单独统计。若用户明确说夜间人员停留也有误报，单独加 `--false`。
  - “烟雾”通常指「烟雾识别」；“非机动车”指「非机动车违停」。
- 误报数不能超过该技能总数；脚本会报错。
- 报表日期：默认取导出数据里最早一条的日期（9 点日报通常算前一天）。如果数据跨天，明确告诉用户归到哪一天。

## 日报流程

1. 找到用户给的导出文件，先列技能：

   ```bash
   python <skill_dir>/scripts/accuracy_report.py daily <导出.xlsx> --list-skills
   ```

2. 把用户口述的误报数映射到精确技能名，组装 `--false` 参数。
3. 跑日报：

   ```bash
   python <skill_dir>/scripts/accuracy_report.py daily <导出.xlsx> \
     --date 2026-10-26 \
     --false "夜间区域入侵=3" --false "区域入侵=1" --false "烟雾识别=all"
   ```

4. 检查输出：
   - 日报：`<导出文件名>_准确率.xlsx`
     - `准确率统计`：技能、总数、误报、准确、准确率、核对方式；
     - `明细核对`：核对说明；
     - `数据记录`：机器可读的台账备份。
   - 台账：默认在导出文件同目录的 `准确率台账.csv`。
5. 向用户汇报：总数、误报、准确、总准确率；低于 90% 的技能；未提及按 0 误报的技能。

示例：74 条，误报 11（夜间区域入侵 3、区域入侵 1、烟雾识别 7），准确 63，准确率 85.1%。

## 月报流程

1. 确认台账路径；默认是日报所在目录的 `准确率台账.csv`。
2. 跑月报：

   ```bash
   python <skill_dir>/scripts/accuracy_report.py monthly \
     --month 2026-10 --ledger <工作目录>/准确率台账.csv
   ```

3. 输出 `月度准确率_YYYY-MM.xlsx`：
   - `月度总览`：KPI、按技能汇总、按日明细；
   - `技能日矩阵`：技能 × 日期准确率，红<80%、黄80–90%、绿≥90%，空白=当天无该技能预警；
   - `趋势图`：每日准确率折线 + 各技能月准确率柱状图；
   - `台账`：当月原始记录。
4. 月报只统计台账里有的日期；缺的日期显示“无数据”。数据完整度 <80% 时，明确告诉用户这是阶段性月报，不要下满月结论。
5. 月初跑上个月：`--month 2026-09`；月中跑当月：只统计到当天。

## 台账

`准确率台账.csv` 列：

`报表日期,预警技能,预警总数,误报数,准确数,准确率,数据源,统计开始,统计结束,生成时间`

- 日报会先删除该日期的旧记录，再写入新记录；同一天重跑会覆盖，不会重复。
- 月报按 `报表日期` + `预警技能` 读取；发现重复记录会报错，先清理台账。
- 台账丢失时，可从各日报的 `数据记录` 工作表恢复。

## 常见问题

- **找不到“预警技能”表头**：确认是“预警详情”导出，或加 `--sheet <工作表名>`。
- **技能名不在导出表**：脚本会列出可选技能；用精确名称重跑。
- **文件被占用**：日报/月报 xlsx 或台账正在 Excel 中打开，关闭后重试。
- **`.xls` 不支持**：先另存为 `.xlsx`。
- **月报没有数据**：台账里没有该月份；先跑对应日期的日报。
