# spd-offline-ledger — 摄像机掉线时长台账 Skill

每周从分公司掉线数据生成"剔除后表"（按运维处/管理处拆分、排序、批量标记），
等运维处反馈后结合太阳能表等材料产出"新表.xlsx"（管理处在线率 + 各类别掉线时长）。

> **口径（2026-09 二次修订）**：`Q + R + S + T = P`
> （安防 + 闸站 + 周界 + 左排 = 运维掉线时长）；
> **U（太阳能）是 Q/R/S/T 里面命中太阳能表的那一部分**，单独填在 U 列，**不参与上面那个加总**。
> N（剔除计划性掉线镜头数量）、O（剔除掉线时长）、P 由人工填好，脚本**不改动**，只重算 Q/R/S/T/U。
> 已作废的旧口径：①`Q+R+T=P`、S/U 不计入 P、`O=剔除时长+S+U`；②`P=Q+R+S+T+U`（U 计入 P）。

## 输入材料

```
工作目录/
├── 北京.csv / 河北.csv / 天津.csv      # 分公司掉线导出(GBK)，每文件：
│                                      #   第1行"统计区间: ..."，第3行"镜头掉线情况"，
│                                      #   第4行表头：序号,一级分组,二级分组,...,镜头名称,设备IP地址,掉线时长,掉线次数
│                                      #   末尾"在线率统计"块：全局,总镜头数量,在线镜头数量,掉线镜头数量,在线率
│                                      #              ,总镜头在线时长,,掉线镜头时长,镜头在线时长率
├── 太阳能摄像机供电时长统计/           # 每运维处一个 xlsx，列：分公司,管理处,摄像机名称,供电电池类型,电池可供电时长(天),备注
│                                      #   用于判定"太阳能"摄像机（U）；按 管理处+镜头名称 匹配
├── 新表.xlsx                          # 台账模板：每管理处一行，A序号 B分公司 C运维处 D管理处 E摄像机数量...
│                                      #   L总镜头数量 M总镜头在线时长 N剔除计划性掉线镜头数量 O剔除掉线时长
│                                      #   P运维掉线时长 Q安防 R闸站 S周界 T左排 U太阳能 V在线率
│                                      #   （N、O、P、L、M、E~K 通常已由用户填好，脚本不动 L~P）
└── 运维处反馈/                         # （第二步才出现）各运维处批注后的剔除后表
```

## 执行流程

### Step 1：生成剔除后表（每管理处一张，按运维处归档）

```bash
python <skill_dir>/scripts/build_tichu.py <工作目录>
```

逻辑规则（按顺序剔除，满足任一即删）：
1. 分组（一级~六级）含 **隐藏**（隐藏目录/临时隐藏/安防-隐藏 等）
2. 二级分组为 **隐藏目录 / 隐藏点位 / 未分组**
3. 分组均为空（二级~六级全空）
4. 掉线时长 **> 8640 分钟**（超6天）

> 注意：**周界行不再剔除**。新口径下周界计入 S（属于 P），必须保留在剔除后表里。

其它处理：
- **保定/顺平合并处理**：保定运维处给的是一张"保定管理处"表，顺平的点位混在里面，
  按**四级分组含"顺平"**拆成 `保定管理处_剔除后表.xlsx` 和 `顺平管理处_剔除后表.xlsx` 两张独立表，
  掉线时长/剔除量/各类时长都各自计算（build_tichu.py 自动拆）
- 同一摄像机（管理处 + 镜头名称 + IP）跨文件/文件内重复 → 保留掉线时长最大值（名称先清洗控制字符）
- 各管理处按掉线时长**正序**排序、重编序号
- 批量掉线标记：剔除后同掉线时长 **≥3 次 且 ≥500 分钟** 的行标黄
- 输出 `剔除后表_按运维处/<运维处>/<管理处>_剔除后表.xlsx` + `总表.xlsx`
- 分公司本部（河北分公司本部/天津分公司本部）单独成表；容雄等"未计算在内"管理处放 `未计入_<名>/`
- 某管理处本周无数据 → 占位表注明；全部被剔除 → 占位表列出剔除行

#### 特殊：邢台管理处（告警导出 → 剔除后表）

邢台管理处在分公司 CSV 里没有数据（整周掉线/超6天被剔），运维处反馈的是
"摄像头离线告警"导出（列：网元名称 / 资源唯一标识 / 事件发生时间 / 事件清除时间 / 离线原因）。
掉线时长 = `Σ(事件清除时间 − 事件发生时间)`（分钟），按相机（资源唯一标识）汇总。

```bash
python <skill_dir>/scripts/build_xingtai_tichu.py <工作目录> [告警文件] [资源唯一标识清单.txt]
```

- 给了**资源唯一标识清单**（每行一个ID，运维处点名确认的相机）：清单内 = 运维（→ P），
  清单外 = 剔除（→ N/O）。**这是首选口径。**（如 2026-09-11 那周运维只认了 7 个ID的相机 180 分钟，
  其余 15 台相机 9500 分钟算剔除）
- 没给清单：按离线原因关键词判定，计划性/人工操作（维护、更换、拆装、远程重启、调整预置位、清理、门禁）= 剔除
- 产出的表保留全部相机，剔除行的备注列写"剔除"；后续 `calc_nop.py` 会把备注含"剔除"的行算进 N/O

### Step 2：等运维处反馈

各运维处在剔除后表上批注"原因/备注"（计划性停电、施工、故障、闪掉线等），
放回 `运维处反馈/<运维处>/<管理处>_剔除后表.xlsx`（列结构可与原表不同，备注列位置不固定：
有的在第12列、有的在第13列；"批量掉线"字样视为批量标记，其余文本视为原因备注）。

### Step 3：产出新表.xlsx

```bash
python <skill_dir>/scripts/calc_nop.py <工作目录> [新表.xlsx路径]     # 先算 N/O/P
python <skill_dir>/scripts/fill_xinbiao.py <工作目录> [新表.xlsx路径] [太阳能目录]   # 再拆 Q/R/S/T/U
```

**N/O/P（calc_nop.py，按备注判断剔除）**：
- 数据源：运维处反馈优先（带备注），否则剔除后表；保定表按四级分组含"顺平"拆出顺平/保定
- **剔除** = 备注里写明计划性/人工/非真实掉线的行，关键词：计划/停电/施工/维护/检修/更换/拆装/拆除/报备/割接/门禁/未掉线/统计出错/建议删除/清理/预置位/移位/远程重启
- 故障类（电缆故障、电池恶化、电压低、泡水、太阳能供电不足等）**不算剔除**，留在 P 里
- `N` = 剔除行数（+ 剔除后表里"隐藏/超6天/空分组"的剔除数）；`O` = 剔除时长（+ 同上）；`P` = 全部掉线时长 − 剔除行时长
- 来源是剔除后表本身且已带备注（如邢台告警表）时，备注已覆盖，不重复加"隐藏/超6天"统计

**Q/R/S/T/U（fill_xinbiao.py）**：
- 每个管理处的数据源：**运维处反馈优先**，没有的用剔除后表_按运维处；邢台等反馈为告警.xls 时按告警专业归类
- **核心口径：`Q + R + S + T = P`**，四项之和严格等于 P（P 已由人工填好，不改）
  - 把 P 对应的行集（基准行 = 批量标记空 且 备注空；基准为空则退化为全部行）按下面优先级分成四类，
    以各类**掉线时长合计为权重**，把 P 按比例拆给 Q/R/S/T
  - 分类优先级（**从具体到宽泛**，顺序很重要，且以**分组名**为准）：
    1. **S 周界**：分组（三~五级）含"周界"（如 `周界安防视频`）→ S
       （注：周界分组名多含"安防"，所以周界要在安防之前判）
    2. **T 左排**：分组或名称含"左排"（如 四级分组=`左排`、名称 `…-左排`）→ T；无任何类别关键字的行也归 T
    3. **R 闸站**：三级分组含"闸站" → R
       **注意**：闸站视频组里名字带"周界"的相机（如 `屯庄南1#保水堰周界01`）算**闸站**，
       不能因为名称里有"周界"就记成 S（徐水、天津就属于这种，两处实际没有周界）
    4. **S 周界（名称）**：安防组里的 `…-周界智能` 球机（顺平/保定）→ S
    5. **Q 安防**：其余（分组含"安防"）→ Q
  - 拆分取整：T 取残差（`T = P − Q − R − S`），保证四项之和 == P
- **U 太阳能**：独立于上面四类，**是 Q/R/S/T 内部的一个子集**，不参与 `Q+R+S+T=P` 的加总
  - 凡是行集里**镜头名称命中** `<太阳能摄像机供电时长统计>/` 表同一管理处的摄像机名 → 计入太阳能权重
  - `U = P × (太阳能行权重 / 四类总权重)`，即 P 中属于太阳能摄像机的那一部分；`U ≤ P`
  - 名称归一：去标点/大小写、去前导编号、去尾部 (全)/(细)
- **N（剔除计划性掉线镜头数量）、O（剔除掉线时长）、P 列不写**，保持人工原值
- 反馈表多为旧口径生成、缺周界行 → 脚本会自动从同管理处剔除后表补入周界行，保证 S 有权重
- 合计行只重算 Q~U；原文件备份为 `新表_备份_新口径.xlsx`，被占用时输出 `新表_已填.xlsx`

## 口径说明

- 在线率 = (总时长 − 掉线时长)/总时长；总时长 = 总镜头数量 × 统计周期分钟数
  （原表"总镜头在线时长" = 总镜头数量 × 1440；新表口径 = 总镜头 × 10080，即7天）
- 掉线时长单位：**分钟**
- **`Q + R + S + T = P`**（2026-09 二次修订）：周界计入 P。
  P/N/O 由人工填好、脚本不改；脚本把 P 按行类别权重拆成 Q/R/S/T。
- **U = Q/R/S/T 中命中太阳能表的那部分**（P 内部子集，不参与加总），`U = P × 太阳能权重占比`。
- 太阳能 U 靠 **镜头名称匹配**太阳能统计表（同管理处）。部分管理处两边命名体系不同
  （如唐县为地点式命名、与掉线表编号式对不上），匹配数为 0 → U=0，属正常数据情况，
  脚本会在报告里打印各管理处匹配结果供核对。
- 太阳能统计表若含"渠道市电"等非太阳能供电行，也一并视为太阳能名单（按表格整表处理）。
